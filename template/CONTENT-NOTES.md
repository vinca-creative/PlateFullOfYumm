# Theme content handoff

The preview includes the home page, 87 published food and recipe articles from the public WordPress posts feed, the About page, a recipe category directory, 18 category archives, a searchable recipe index, search results, and a device-local saved recipe box.

Content was imported from the public WordPress REST API on 18 October 2026. Recipe ingredient quantities and instructions are preserved from the source. Recipe card styling, ingredient checkboxes, printing, and an ad-free cooking view are provided for the 78 articles with structured recipe-card markup. The other nine articles retain their published content without invented recipe instructions. Save IDs remain compatible with the original four home-page recipes.

Article photographs within imported content continue to use their public WordPress image URLs. The original four home-page photographs remain local assets. Existing public article links point to matching preview pages where available. Other external links retain their original destinations.

This is a static design preview, not a WordPress theme installation. WordPress comments, ratings, login, and plugin dashboards have not been simulated. Empty plugin-generated taxonomy landing pages are not presented as working features. No live ads are requested. AdSense activation and WordPress integration remain separate deployment work. The original website is unchanged.

Validation: JavaScript syntax checked for every page and the shared script; all local link and image targets checked. Browser visual QA was unavailable in this environment. Production AdSense behavior and print rendering require browser checks before installation.
